Super Slides — HTML presentations

Super Slides turns plain HTML sections into a web presentation and shows how the deck was read, with no runtime dependencies or hosted service required.

A presentation made from HTML

A stylesheet and a script add slide navigation, a progress display and a reading report to ordinary HTML sections. The same library can also measure sections of a scrolling page.

The report tracks reading time per slide, revisits, the furthest slide reached and where a reading session ended. Time in a background tab is excluded so that leaving a deck open does not count as reading it.

  • Super Slides source and examples

Local by default

The default report stays in browser memory. There are no default cookies, persistent storage or network reporting. A developer can explicitly configure a collector if a project needs one.

The project is MIT licensed and includes keyboard navigation, print styles and examples. The repository explains integration, styling, reporting and the distinction between local statistics and an explicitly enabled collection endpoint.
