AFS volunteer maps & AFSER MCP

Alongside volunteering as an AFS sending coordinator, I build tools that help volunteers find relevant exchange-program tasks and understand their geographic context.

Maps for volunteer coordination

The AFS map brings together anonymous views of sending interviews, outgoing exchange students, hosted students, host families and returnees. Chapter selection and location-based filtering help volunteers focus on relevant work.

The public view uses approximate locations and anonymous records. Detailed source records remain behind AFSER's own login. The map does not publish names, contact details or household addresses.

A separate local data service

The companion AFSER service separates private source acquisition from the public map. It stores source data locally and exposes bounded anonymous results through an API and the Model Context Protocol (MCP).

This separation lets an assistant work with relevant anonymous records while the full source remains on the owner's computer. The public code repository contains the implementation and setup documentation, rather than a personal dataset.
